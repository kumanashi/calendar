# 個人排班行事曆 v4.8

v4.8 維持 v4.7.2 的核心架構：Google Calendar、Drive App Data、PIN、收入、批次刪除與固定排班均保留。

## v4.8 變更

1. 右下角「同步」改名為「設定」
   - 設定視窗標題也統一改成「設定」。

2. 修正彈窗拖曳時誤關閉
   - 背景遮罩只有在 pointer down 與 pointer up 都發生在遮罩本身、且移動距離小於 6px 時才會關閉。
   - 從輸入框、表單或彈窗內拖曳到外面，不會再把彈窗關掉。

3. 背景圖片
   - 設定中可選擇 / 移除背景圖片。
   - 圖片在瀏覽器端縮小並轉 JPEG 後存入 Drive App Data。
   - 換裝置載入 App Data 後會同步背景。
   - 有背景時卡片會使用半透明 + blur，維持可讀性。

4. 診次種類與顏色
   - 設定中可修改各診次名稱與顏色。
   - 可新增自訂診次種類。
   - 可刪除未被任何排班使用的種類。
   - 若仍有事件使用該種類，系統會阻止刪除，避免既有排班失去分類。

5. Google / 本機快取狀態 icon
   - 版本號旁新增狀態圖示。
   - 雲朵：Google / App Data 已載入或同步。
   - 硬碟：目前顯示本機快取，或尚有設定待同步。

6. PIN 畫面
   - 一般解鎖畫面只顯示「個人排班表」、PIN 輸入框、錯誤訊息（僅錯誤時）與「解鎖」按鈕。
   - 第一次設定 PIN / 新裝置需要 Google 授權時，仍保留必要的設定介面。
