# 個人排班行事曆 v4.5

v4.5 僅修改兩個部分，其餘沿用 v4.4 架構與版面。

## 變更

1. 標題
   - 刪除 `My roster`
   - 在「個人排班表」旁顯示版本號 `v4.5`

2. 批次刪除
   - 右下角新增「☑ 批次刪除」
   - 點擊後進入批次刪除模式
   - 月曆上的排班事件會顯示核取方塊
   - 可一次選取多筆事件
   - 右下角按鈕會顯示「刪除已選 (N)」
   - 再按一次會確認後一次刪除選取事件，並同步刪除 Google Calendar 中的對應事件
   - 若尚未勾選任何事件，再按一次可離開批次刪除模式

## 其餘功能

Google Calendar、Drive App Data、收入、固定排班、單次排班、顏色設定與 Apple iCal 邏輯均維持 v4.4。
