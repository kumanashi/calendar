MONTHLY INCOME

本月收入設定

節費與 PPF 由當月各診次自動加總；牌費、額外支援與健保費用每月設定一次。

牌費、額外支援與健保費用會儲存在 Google Drive App Data；各診次的節費與 PPF 則會隨 Google Calendar 事件同步。所有收入資料可跨裝置共用，且不會建立額外的「收入設定」日曆事件。

SETTINGS

設定

Google Calendar

建議建立一個獨立的「排班」日曆。Calendar ID、Apple iCal URL、收入設定與顏色會同步到 Google Drive App Data。

Apple Calendar

貼上 Google 排班日曆的 Secret address in iCal format。網址會存入 Drive App Data，不會寫入 GitHub 或一般「我的雲端硬碟」檔案列表。

診次種類與顏色

可統一修改名稱與顏色，也可新增或刪除種類。仍有排班使用中的種類不可刪除。

背景圖片

可上傳自己的背景圖片；圖片會先縮小壓縮，再存入 Google Drive App Data，並同步到其他裝置。

無背景圖片

建議使用橫向照片；系統會自動壓縮以避免 App Data 過大。

Drive App Data

尚未檢查

尚未檢查雲端設定。Google Calendar 可獨立使用；App Data 若暫時不可用，設定會先保存在本機。

啟用 Google Drive API

狀態會區分：尚未授權、Drive API 未啟用、讀取失敗、使用本機快取、已同步。App Data 異常不會再鎖住其他按鈕。
